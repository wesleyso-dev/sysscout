# SysScout

A lightweight, cross-platform, read-only command-line tool for IT diagnostics:
system health (CPU, memory, disk, OS), network connectivity (DNS, TCP, HTTPS/TLS),
troubleshooting recommendations, and JSON reports.

> Work in progress. Full documentation arrives in Stage 6.

## Quick start

```bash
python -m venv .venv
# Windows:  .\.venv\Scripts\Activate.ps1
# macOS/Linux:  source .venv/bin/activate
pip install -r requirements.txt
python -m sysscout --help
```
